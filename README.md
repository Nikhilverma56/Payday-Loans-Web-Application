# Payday Loans Web Application

## Overview

Payday Loans Web Application is a simple web application developed using Node.js, EJS, and MySQL. The main purpose of this project is to allow users to apply for payday loans online by filling out an application form.

Users can click on the Apply button, enter their personal and loan-related information, and submit the application through the website.

---

# Features

* Simple and user-friendly interface
* Loan application form
* User information submission
* Data storage using MySQL database
* Dynamic frontend using EJS templates
* Backend developed with Node.js and Express.js
* Responsive web design

---


# How It Works

1. User opens the web application.
2. User clicks on the Apply button.
3. A loan application form is displayed.
4. User fills in personal and loan details.
5. Information is stored in the MySQL database.
6. Application is submitted successfully.
